# Legal Documents for CPFT

This directory contains the legal documents for CPFT (Cross-Platform File Transfer).

## Files

### Markdown Versions (for documentation)
- `TERMS_OF_USE.md` - Terms of Use in Markdown format
- `PRIVACY_POLICY.md` - Privacy Policy in Markdown format

### HTML Versions (for website hosting)
- `terms.html` - Terms of Use as a styled HTML page
- `privacy.html` - Privacy Policy as a styled HTML page

## Usage

### In-App Links
The app currently links to:
- Terms of Use: `https://cpft.app/terms`
- Privacy Policy: `https://cpft.app/privacy`

### Hosting Instructions
1. Host the HTML files on your website at the above URLs
2. Or update the app's settings screen to point to your actual URLs
3. Customize the jurisdiction and contact information as needed

## Customization Required

Before using these documents:

1. **Jurisdiction**: Replace `[Jurisdiction]` with your actual legal jurisdiction
2. **Contact Information**: Update email addresses and contact details
3. **Company Information**: Add your company name and registration details
4. **App Store IDs**: Update store links in the app when published

## Legal Review

⚠️ **Important**: These documents are templates and should be reviewed by a qualified attorney before use. They are provided as examples and may need modification based on your specific legal requirements and jurisdiction.

## Updates

When updating these documents:
1. Update the "Last Updated" date
2. Notify users through the app if changes are significant
3. Keep both Markdown and HTML versions in sync
