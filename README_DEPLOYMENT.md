# 🚀 CPFT - Hybrid SEO + Flutter Deployment

A professional setup serving a static HTML landing page at the root (`/`) for SEO, with the Flutter web app in a subfolder (`/app/`).

## 🎯 Architecture

```
Your Domain (cpft.io)
│
├─ / (Root)
│  └─ dist/index.html
│     → SEO-optimized landing page
│     → Links to /app/
│
└─ /app/ (Subfolder)
   └─ dist/app/
      → Flutter web application
      → All assets under /app/
```

## 📁 What's in `dist/`?

This is your **deployment folder**. Upload only this to your server.

```
dist/
├── index.html              # Landing page (20KB)
├── app/                    # Flutter app (3-5MB)
│   ├── index.html
│   ├── main.dart.js        # Main app code (3.3MB)
│   ├── flutter_bootstrap.js
│   ├── flutter_service_worker.js
│   ├── canvaskit/          # WebAssembly runtime
│   ├── assets/             # Images, fonts, data
│   └── ...
├── server.js               # Local dev server
└── package.json
```

## 🚀 Quick Commands

### 1. **Test Locally**
```bash
cd dist
node server.js
# Visit http://localhost:3000/
```

### 2. **Build & Update Flutter App**
```bash
./deploy.sh
# Automatically rebuilds and updates dist/app/
```

### 3. **Deploy to Production**
```bash
# Upload dist/ to your server
rsync -avz dist/ user@server.com:/var/www/cpft/
```

## 🔄 Update Workflow

### When you modify the Flutter app:
1. Edit files in `lib/`
2. Run `./deploy.sh`
3. Upload `dist/` folder

### When you modify the landing page:
1. Edit `dist/index.html`
2. Upload `dist/` folder (or just index.html)

## 🌐 Deployment Locations

### Vercel / Netlify
1. Connect your Git repo
2. Build command: `./deploy.sh`
3. Publish directory: `dist/`

### Traditional Server (Nginx/Apache)
1. Upload `dist/` to `/var/www/cpft/`
2. Point domain to `/var/www/cpft/`
3. Server automatically serves `index.html` at root
4. Server rewrites `/app/` to `/app/index.html`

See `DEPLOYMENT_GUIDE.md` for server configs.

### Docker
```dockerfile
FROM nginx:alpine
COPY dist/ /usr/share/nginx/html/
EXPOSE 80
```

## 🐛 Troubleshooting

### App loads at `/app/` but shows blank page
- Check browser console (F12) for errors
- Verify `main.dart.js` is loading
- Ensure `--base-href /app/` is set in build

### Landing page doesn't load
- Check `dist/index.html` exists
- Verify server is pointing to `dist/` folder
- Check for 404 in browser network tab

### Changes don't appear
- Did you run `./deploy.sh`?
- Hard refresh: Ctrl+Shift+R or Cmd+Shift+R
- Check browser cache in DevTools

### Deploy script fails
- Run `flutter clean` then `./deploy.sh`
- Check you have Flutter 3.0+
- Ensure `dist/` folder exists

## 📊 Performance Tips

- Landing page loads in ~100ms
- Flutter app loads in ~2-3s first load
- Use CDN for assets in production
- Enable gzip compression on server
- Set long cache headers for JS/CSS

See `DEPLOYMENT_GUIDE.md` for detailed optimization.

## 🔐 Security Headers

Add these to your server config for production:

```

X-Content-Type-Options: nosniff
X-Frame-Options: SAMEORIGIN
X-XSS-Protection: 1; mode=block
```
